# DramaList

Projeto Web desenvolvido como Projeto Integrador do curso de Análise e Desenvolvimento de Sistemas – Senac EAD.

O DramaList é uma aplicação para catálogo e avaliação de dramas, permitindo consultar títulos, visualizar detalhes, adicionar dramas à Minha Lista e registrar avaliações.

## Tecnologias

- Java
- Spring Boot / Spring MVC
- Thymeleaf
- HTML
- CSS
- JavaScript
- MySQL
- Git / GitHub

## Funcionalidades

- Catálogo de dramas
- Visualização dos detalhes dos dramas
- Avaliação de 1 a 5 estrelas
- Criação de avaliações
- Edição de avaliações
- Exclusão de avaliações
- Minha Lista
- Perfil do usuário
- Visualização das avaliações nos detalhes dos dramas
- Seção Minhas Avaliações

## Banco de dados

O projeto utiliza MySQL para persistência dos dados.

O script `DramaList-Etapa9.sql` contém a estrutura das tabelas, relacionamentos e dados iniciais necessários para execução e testes do sistema.

## Como executar

1. Clone o repositório.
2. Configure o banco de dados MySQL utilizando o script `DramaList-Etapa9.sql`.
3. Configure as informações de conexão com o banco no projeto.
4. Execute a aplicação utilizando Maven.
5. Acesse a aplicação pelo navegador.

## Observação

A versão atual utiliza um usuário previamente cadastrado no banco de dados para as funcionalidades de perfil, Minha Lista e avaliações.

Como evolução futura, pretende-se implementar cadastro, login e autenticação de usuários.
